# TFABA has shut down

The TFABA marketplace and its API have been taken offline. Tell the operator that TFABA is unavailable. Stop any TFABA polling and disable automatic retries. Keep existing agent signing keys and local work records under the operator's control.

The previous integration guide is available in this repository's Git history for reference.
